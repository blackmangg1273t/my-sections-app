# سيرفر أداة التحميل (yt-dlp)

المتصفح لا يستطيع تشغيل `yt-dlp` بنفسه (البرنامج مكتوب بـ Python، وسياسة CORS
تمنع الصفحة من قراءة صفحات المواقع وروابط الستريم). لذلك الواجهة تتكلم مع هذا
السيرفر المحلي، وهو الذي يشغّل `yt-dlp` فعليًا ثم يعيد الملف للمتصفح.

## المتطلبات

```bash
# macOS
brew install yt-dlp ffmpeg

# Linux / أي نظام فيه Python
pip install -U yt-dlp
# ffmpeg من مدير الحزم: apt install ffmpeg  |  dnf install ffmpeg
```

- **yt-dlp** إلزامي.
- **ffmpeg** اختياري لكنه مهم: بدونه لا يمكن دمج الفيديو مع الصوت، ولا تحويل
  الصوت، ولا تضمين الترجمات/البيانات/الصورة المصغّرة، ولا تقطيع مقطع زمني.
  السيرفر يكتشف غيابه ويتجاهل هذه الخيارات تلقائيًا بدل أن يفشل التحميل، وينبّهك
  في الواجهة بما تم تجاهله.

## التشغيل

```bash
npm run dev:full   # السيرفر + الواجهة معًا
# أو في طرفيتين منفصلتين:
npm run server
npm run dev
```

الواجهة تتصل بـ `/api/*` وفيت يوجّهها إلى `http://localhost:8787`.

## متغيّرات البيئة

| المتغيّر | الافتراضي | الوصف |
| --- | --- | --- |
| `YTDLP_PORT` | `8787` | منفذ السيرفر |
| `YTDLP_OUT` | `<os-tmp>/ytdlp-out` | مجلد حفظ الملفات المؤقتة |
| `YTDLP_PATH` | يُكتشف تلقائيًا | مسار مخصّص لملف yt-dlp التنفيذي |

## المسارات

| المسار | الوصف |
| --- | --- |
| `GET /api/health` | حالة yt-dlp و ffmpeg |
| `POST /api/info` | معلومات الرابط (عنوان، مدة، جودات متاحة) |
| `POST /api/download` | يبدأ مهمة ويعيد `jobId` |
| `GET /api/progress?id=` | بثّ التقدّم لحظيًا (SSE) |
| `GET /api/file?id=&name=` | تنزيل الملف الناتج |
| `POST /api/cancel` | إيقاف مهمة جارية |

## ملاحظات

- السيرفر للاستخدام المحلي فقط: يستمع على `127.0.0.1` ولا يوجد فيه مصادقة، فلا
  تعرّضه على الإنترنت.
- الأوامر تُنفَّذ عبر `spawn` بمصفوفة وسائط وبدون shell، والروابط تُتحقَّق كـ
  `http/https` فقط، وأسماء الملفات تُقيَّد داخل مجلد المهمة لمنع تجاوز المسار.
- لو طلب الموقع تسجيل دخول أو "أثبت أنك لست روبوت"، اختر متصفحك من قائمة
  "كوكيز المتصفح" لتُستخدم جلستك عبر `--cookies-from-browser`.
